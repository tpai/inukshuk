# Ambient recordings (optional)

Drop CC0 `.mp3` files here with these names and the game plays them instead of the synthesised fallback:

- `bird-1.mp3`, `bird-2.mp3`, `bird-3.mp3` — short single calls, under 1.5 s
- `crickets.mp3` — seamless loop, summer and autumn nights
- `clack-1.mp3`, `clack-2.mp3` — stone on stone, under 0.3 s

Wind is always synthesised so it can follow the on-screen gusts.
